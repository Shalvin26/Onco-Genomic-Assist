Genomic Variant & Precision Medicine Decision Support System

An end-to-end bioinformatics & health-tech web application designed to extract genomic findings from unstructured clinical reports, query NCBI ClinVar APIs, and present physicians with structured variant classifications (AMP/ASCO/CAP guidelines).

## Tech Stack
- Frontend: React, Tailwind CSS, Framer Motion, Axios
- Backend: Node.js, Express.js, MongoDB Atlas, Mongoose
- Genomic Databases: NCBI ClinVar

## Key Features
- Dynamic text extraction of gene findings (EGFR, BRCA1, etc.)
- Automated mapping to ClinVar Variation IDs and canonical URLs
- Tier-based somatic and germline variant classification breakdown
- Interactive UI with Framer Motion cards and deep-dive modals
